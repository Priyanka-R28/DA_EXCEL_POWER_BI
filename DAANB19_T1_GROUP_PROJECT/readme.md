# 🎵 Musical Data Analytics — Spotify, YouTube & TikTok

## 📌 Project Overview

This project analyzes music performance data across **Spotify, YouTube, and TikTok** to identify trends, relationships, and opportunities for music promotion.

The project focuses on **Spotify popularity, Spotify playlist count, Spotify streams, YouTube views, TikTok likes, and release year**.

The analysis was performed using **Excel and Power BI**, with the final results presented through an interactive dashboard and supporting project documentation.

---

## 🎯 Project Objectives

* Analyze the relationship between **Spotify popularity and playlist count**
* Analyze **Spotify popularity vs TikTok likes**
* Examine **total YouTube views by release year**
* Compare **Spotify streams and YouTube views**
* Identify high-performing and potentially emerging songs
* Generate data-driven business recommendations

---
